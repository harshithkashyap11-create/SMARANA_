# 04 — API Contract (v1)

Base: `/api/v1/`. JSON. Auth: `Authorization: Bearer <access>`. All timestamps ISO-8601 UTC. Pagination: `?page=&page_size=` (default 50) returning `{count, next, previous, results}`. Errors: `{"detail": "...", "code": "..."}` — user-safe messages; the frontend maps `code` to translated copy.

The OpenAPI schema generated by drf-spectacular at `/api/schema/` is the executable contract; the frontend client is generated from it (`npm run api:gen`). This doc is the human summary; if they disagree, fix the code and regenerate.

## Auth

| Method | Path | Who | Notes |
|---|---|---|---|
| POST | `auth/patient/login/` | anon | `{login_id, pin, device_id}` → `{access, refresh, user}`. 5 fails → 423 Locked + caregiver alert |
| POST | `auth/login/` | anon | `{email_or_phone, password, device_id}` → tokens. Doctors/caregivers must be `is_approved` |
| POST | `auth/refresh/` | any | `{refresh}` → `{access, refresh}` (rotated) |
| POST | `auth/logout/` | any | revokes refresh |
| GET | `auth/me/` | any | user + role + preferences + assignments summary |
| PATCH | `auth/me/preferences/` | any | `{preferred_language, theme, font_scale, accessibility}` |
| POST | `auth/patient/pin-reset/` | caregiver | `{patient_id, new_pin}` (primary caregiver only) |

## Response shape examples

`POST patients/{id}/game-sessions/` →
```json
{
  "session": {"id":"…","game":"sequence_recall","level":3,"accuracy":0.55,"mean_reaction_ms":2100,"mistakes":5,"hints_used":1,"rounds":6,"completed":true},
  "difficulty_state": {"game":"sequence_recall","level":2,"locked_by_doctor":false,"cap_level":null},
  "change": {"from_level":3,"to_level":2,"reason_code":"demote","explanation":"Accuracy stayed under 60% across 3 rounds while reaction time increased."},
  "message_key": "dda.easier_next_time"
}
```
`message_key` maps to translated, supportive patient copy. The `explanation` is for doctors/caregivers and is never shown to patients.
